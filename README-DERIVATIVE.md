# 画面設計ツール派生版

このディレクトリは `saksakchoc/whiteboard` をコピー元にした別プロジェクトです。公開中の既存ホワイトボードには変更を加えません。

- コピー元: https://github.com/saksakchoc/whiteboard
- コピー元リビジョン: `300a17b9859da81a2efd44db8dc08890f19eb543`
- 既存の自由描画: `/b/:boardId`
- 新しい画面設計: `/d/:boardId`

## MVPで追加したもの

- 画面ワイヤーフレーム
- ボタン、入力欄、テキスト、一覧、画像のUI部品
- 画面間の遷移矢印と、操作・条件の記録
- 操作時の動作メモ
- 未決定事項、候補、決定済み状態
- Socket.IOを使った新しい設計要素の共同編集
- JSONとMarkdown（Codex向け）の仕様出力
- 元の自由描画画面への行き来

## 起動

```text
npm install
npm start
```

既定では `http://localhost:3001/whiteboard/` です。トップ画面の「画面設計を作成」から開始します。

## 注意

コピー元の `public/templates/*.png` 4点は、現在の作業環境ではバイナリ取得を完了できなかったため含めていません。画面設計モードでは使用しませんが、自由描画側のテンプレートも完全に再現する場合はコピー元から追加してください。
